# Curve Analysis

We provide an analysis of different Ethereum yield curves (resp. issuance curves) along a number of different dimensions and the trade-offs associated to each of them.

## Tempered Issuance


**Yield Function:** $y_i (s) = 1 + \frac{2.6 \cdot 64}{\sqrt{s} (1 + \frac{s}{k})}$ 

**Issuance Function:** $i (s) = 1 + \frac{2.6 \cdot 64 \cdot \sqrt{s}}{(1 + \frac{s}{k})}$
